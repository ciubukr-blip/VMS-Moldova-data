# VMS Moldova – date și versiuni

Acest depozit public conține **datele publice** (`data/vms_data.json`) și **versiunile APK** (secțiunea
Releases) ale aplicației Android **VMS Moldova**. Aplicația le descarcă de aici.

Codul sursă al aplicației nu se află aici.

- **Aplicație neoficială.** VMS Moldova nu este un produs al Ministerului Finanțelor sau al Băncii Naționale a
  Moldovei și nu este afiliată cu ele. Datele provin din surse publice (mf.gov.md, bnm.md).
- **Nu este consultanță de investiții.** Informațiile și calculele sunt orientative.
- **Confidențialitate.** Vezi [PRIVACY.md](PRIVACY.md). Aplicația nu colectează date personale, iar portofoliul
  rămâne doar pe telefonul tău.
